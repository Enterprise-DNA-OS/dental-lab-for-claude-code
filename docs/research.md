## Annual bill first

[Labtrac pricing](https://www.labtrac.com/Pricing) lists Enterprise at US$2,000 per month for 25 users and US$3,500 for 50 users, before VAT and taxes. Twelve monthly payments are US$24,000 and US$42,000. Those are public list-price scenarios, not verified ANZ invoices or measured savings. The same page lists Professional+ at US$899 per month for up to 25 users, so Enterprise is not the only option for a lab of that size. Enterprise includes consultancy time and API activity allowances as well as software.

## Product and import evidence

[Features](https://labtrac.com/Features) describes production handoffs, technician work, scanner intake and file context. [The object graph](https://api.labtrac.com/) documents cases, orders, dentists and inventory. [Legacy workflow manual](https://github.com/labtrac/legacy-docs/blob/master/Labtrac.Manual.md) explains staged work and dentist return. [Reports](https://docs.labtrac.com/team-docs/documentation/reports) and [FAQ](https://docs.labtrac.com/team-docs/documentation/faqs) provide reporting and document context.

The import uses a declared mapped contract, not an invented standard export. Vendor-assisted extraction and real-record reconciliation remain prerequisites. No source supports a guarantee that every lab can switch in a day. No claim is made that Labtrac lacks a particular analysis. The owned record's questions are independently tested.

No measured savings, customer names, unsupported rivals or subscription-cancellation promises appear on the page. Price observations are stored in the Command Centre target's prices list.
