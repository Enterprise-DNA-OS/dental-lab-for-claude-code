# A production desk without a front end

The database holds the lab record. Claude Code, Codex, OpenCode or Cursor reads and changes it through one CLI. Branded HTML reports show the week, material traces and evidence reviews. They contain no controls that change data.

A screen gives a technician quick barcode scanning, mobile entry, offline capture, CAD previews and drag-and-drop scheduling. This base does not supply those capabilities. It also has no scanner feed, customer portal or multi-user login. Keep specialist design and clinical systems in place. Enterprise DNA can build the needed screens and connections around the owned record.

The useful starting point is a lab manager's production review, with dated work, named people and evidence. No browser service is needed to run it.
